# Open data manifest

Files in this folder were downloaded on 24 Nov 2026 with `curl` from Bayanat, the UAE Government open data portal (https://bayanat.ae). They are unmodified copies; file names are the ones the portal sent in its `Content-Disposition` header.

Licence: the portal's Copyright page states that datasets are published under the Creative Commons Attribution 4.0 International License (CC BY 4.0), which allows copying and redistribution with attribution, a link to the licence, and an indication of changes (https://bayanat.ae/en/Copyright, read 24 Nov 2026). Attribute each file to its publisher and to Bayanat.

Download URL pattern: `https://bayanat.ae/api/DatasetResources/DownloadSingle?resourceID=<resource id>&fileName=<resource name>`. The resource ids below are the ones the dataset pages exposed on the day; the portal's ids look like opaque tokens, so if a link stops working, open the dataset page and use its Download button.
